RULES AND INSTRUCTIONS

Please read all instructions carefully before starting the examination.

1. GENERAL INSTRUCTIONS

  1. This is an offline examination system. No Internet connection is required.
  2. Make sure you have selected the topics you have prepared before starting the examination.
  3. Once the examination begins, the selected topics cannot be changed.
  4. Do not close the application or browser during the examination.
  5. Your name, roll number, selected topics, answers, code submissions and examination results will be recorded.
  6. Questions are selected randomly from the available question database.
  7. Questions may be repeated for different students because each computer operates independently.
  8. You may skip a question and return to it later where navigation is available.
  9. The examination will automatically proceed/finish when the relevant section's timer expires.
  10. Follow the examination instructions carefully.

2. APTITUDE SECTION

  1. The Aptitude section contains exactly 20 questions.
  2. The total time available for the Aptitude section is 30 minutes.
  3. Questions are randomly selected based on the Aptitude topics chosen by the student.
  4. Each question has multiple-choice options.
  5. Select the option you believe is correct.
  6. You may skip a question.
  7. Skipped questions can be revisited before the Aptitude timer expires.
  8. The system records:
    • Attempted questions
    • Correct answers
    • Wrong answers
    • Skipped questions
  9. When the 30-minute timer reaches zero, the Aptitude section will automatically end.
  10. The Aptitude result will be calculated after submission/section completion.

3. DSA PROGRAMMING SECTION

  1. The DSA section contains exactly 2 programming problems.
  2. One problem will be Easy difficulty.
  3. One problem will be Medium difficulty.
  4. Problems are randomly selected from the DSA topics chosen by the student.
  5. The Easy problem has a time limit of 25 minutes.
  6. The Medium problem has a time limit of 30 minutes.
  7. Java is the supported programming language.
  8. Each problem provides:
    • Problem statement
    • Examples
    • Constraints
    • Starter code
  9. You may modify the provided starter code.
  10. Use the Run button to test your program against the provided sample test cases.
  11. Use the Reset button to restore the original starter code.
  12. Use the Submit button to submit your final solution.
  13. Submission will eventually be checked against all test cases.
  14. The final DSA result will record the verdict and test cases passed.

4. CODE EXECUTION RULES

Run

Executes the current code against the available sample test cases. Shows standard output or compilation/runtime errors.

Reset

Removes all changes made by the student and restores the original starter code provided with the problem.

Submit

Checks the submitted program against all hidden test cases. Evaluates final verdict:

Accepted Wrong Answer Compilation Error Runtime Error

5. IMPORTANT NOTICE

⚠ Warning: Examination Session Integrity

Once the examination begins, do not close the application or restart the computer. Doing so may interrupt the examination session. Make sure you are ready before clicking Start Examination.
